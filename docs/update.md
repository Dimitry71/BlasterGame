# Інструкція з оновлення проєкту (Update Guide)

## 🧾 Мета
Забезпечити безпечне та контрольоване оновлення проєкту Unreal Engine 5 у production-середовищі без втрати даних і з мінімальним простоєм.

---

## ✅ Передумови

- Доступ до production-сервера
- Повна або інкрементальна резервна копія (див. `backup.md`)
- Зібраний оновлений білд проєкту (`.exe`, `.pak` файли тощо)
- Доступ до журналів попередніх запусків
- Встановлений Git або SCP для передачі файлів

---

## 🔧 Підготовка до оновлення

1. **Повідомлення команди**  
   Узгодити час оновлення з командою або клієнтом, попередити про можливий короткий простій.

2. **Резервне копіювання**  
   Створити копію:
   - Системних файлів
   - Налаштувань
   - Користувацьких збережень (за потреби)

3. **Перевірка сумісності**  
   - Перевірити, що новий білд сумісний з поточними конфігураціями (наприклад, командний рядок запуску, ini-файли).
   - Якщо є оновлення рушія — окремо провести тестове розгортання на dev-сервері.

4. **Підготовка сервера**  
   Очистити тимчасові файли, переконатися в наявності вільного місця на диску.
