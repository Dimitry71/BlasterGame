# 🧾 Інструкція з генерації документації коду

Ця інструкція описує кроки для автоматичної генерації документації проєкту на **C++** під **Unreal Engine 5** з використанням **Doxygen**.

---

## 📥 Встановлення Doxygen

1. Перейдіть на офіційний сайт: [https://www.doxygen.nl/download.html](https://www.doxygen.nl/download.html)
2. Завантажте та встановіть версію для вашої ОС.
3. (Рекомендовано) Додайте `doxygen.exe` до системної змінної `PATH` для зручності запуску з командного рядка.

---

## ⚙️ Створення конфігурації

У кореневій директорії проєкту:

```bash
doxygen -g Doxyfile
doxygen Doxyfile - для генерації документації
